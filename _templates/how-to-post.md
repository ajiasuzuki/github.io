# 活動報告の書き方

このフォルダ（`_templates`）は、サイトには公開されません。メモ用です。

## 記事を1本公開する手順

1. GitHubのこのリポジトリで `_posts` フォルダを開く。
2. 右上の **Add file → Create new file** を押す。
3. ファイル名を `日付-英数字の名前.md` にする。
   - 例: `2026-12-03-hospital-visit.md`
   - 英数字の部分が、そのままURLになる → `https://ajiasuzuki.com/news/hospital-visit/`
   - 日本語は使わない。ハイフンでつなぐ。
4. 下の「記事のひな形」を貼り付けて、書き換える。
5. **Commit changes** を押す。1〜2分後にサイトへ反映される。

## 記事のひな形

```markdown
---
layout: post
title: "記事のタイトル"
description: "検索結果と記事一覧に出る説明文。60〜120字くらい。"
---

本文をここから書く。

## 見出し（大）

段落。空行で区切る。

### 見出し（小）

- 箇条書き
- 箇条書き

[リンクの文字](https://example.com/)
```

- 日付は、ファイル名の日付が記事の日付になる。未来の日付にすると、その日まで公開されない。
- タイトルに `:` が入るときは、必ず `"` で囲む。

## 公開前チェック（守秘義務）

- [ ] 実習生・取引先・病院・保険会社が特定できる名前や写真が入っていない
- [ ] 日時や場所の組み合わせで、個人や案件が特定できない
- [ ] 内容を書く許可を、必要な相手から得ている

## 最初の記事を公開するとき

最初の記事を公開したら、トップページ（`index.html`）のヘッダーにも
「活動報告」へのリンクを足す。`index.html` の次の部分を探す。

```html
      <a href="https://ajiasuzuki.com/#profile">プロフィール</a>
```

その下の行に、次を足す。

```html
      <a href="https://ajiasuzuki.com/news/">活動報告</a>
```

記事が1本もない間は、`/news/` は検索に表示されない設定になっている（記事を公開すると自動で外れる）。
